# Viva Questions and Short Answers

1. What is customer segmentation?
Customer segmentation is the process of grouping customers with similar characteristics or behavior.

2. Why did you use K-Means?
K-Means is a simple and widely used unsupervised learning algorithm for grouping similar data points.

3. Is this supervised or unsupervised learning?
Unsupervised learning because the dataset does not contain predefined segment labels.

4. What is K?
K is the number of clusters we ask K-Means to create.

5. How did you select K?
We compared clustering quality using silhouette scores for several K values.

6. What is standardization?
It converts features to a comparable scale so features with large numeric values do not dominate.

7. Why use PCA?
PCA reduces dimensions and helps visualize high-dimensional customer data in two dimensions.

8. What is a cluster?
A cluster is a group of customers with similar selected behavior patterns.

9. What is silhouette score?
It measures how well observations fit within their own cluster compared with other clusters.

10. What is Power BI used for?
Power BI is used to create an interactive dashboard and communicate the segmentation results.

11. What business value does the project provide?
It helps businesses target different customer groups with more relevant marketing and retention strategies.

12. What are the main features used?
Annual income, purchase frequency, average order value, total spend, recency, and discount usage.

13. What is an outlier?
An observation that is unusually different from most other observations.

14. What are the limitations?
The dataset is synthetic for academic demonstration, and customer behavior can change over time.

15. How can the project be improved?
Use real transaction data, add RFM analysis, test DBSCAN/Gaussian Mixture Models, and build a live dashboard.
